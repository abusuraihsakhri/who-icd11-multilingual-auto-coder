Implemented software rules

  • Primary metric above 25: elevated.
  • Secondary metric above 12: elevated; critical flag: critical.
  • Descriptor containing DISCORDANT, ANOMALY, MUTANT, VIOLATION, FAIL, or REJECT: elevated.
  • Critical urgency takes precedence over elevated urgency.

These are test thresholds only. The Python service includes an in-memory HMAC audit trail; the browser preview does not issue audit signatures or assign any ICD-11 codes.
